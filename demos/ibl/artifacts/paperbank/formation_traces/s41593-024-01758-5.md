## Starting background

- Action selection requires linking an option's anticipated value to the action or location associated with that option, making value binding a central problem in neuroeconomics.
- Prior representational-geometry work shows that population activity can organize task-relevant information into structured, low-dimensional subspaces while supporting generalization to novel configurations.
- Theoretical alternatives frame a trade-off: parallel value codes support abstraction across positions, whereas more separated or orthogonal codes preserve feature-position bindings but reduce generalization.

## Unresolved gap

The provided evidence supports an unresolved theoretical tension over how neural populations can preserve which value belongs to which offer without sacrificing an abstract value code that transfers across offer positions. It remained unclear whether an intermediate, semi-orthogonal geometry could jointly support binding and generalization, and whether that geometry would predict observable choice errors.

## Dataset opportunity

The study used sequential two-option risky-choice trials in which offer location and presentation order were varied, followed by simultaneous reappearance and a behavioral choice, while neural population activity was recorded during the task.

Because spatial location and temporal order could be compared while offer values varied and choice behavior was observed, the dataset made it possible to distinguish spatial from temporal binding and to relate population subspace geometry to both cross-position value generalization and behavioral misbinding. The combination of population recordings and errors therefore allowed the theoretical trade-off to be tested against neural and behavioral observations rather than decoding alone.

## Resulting question

Do neural populations represent the values of multiple sequential offers in distinct but not fully separate subspaces, such that the code preserves offer identity while allowing value information to generalize across positions and presentation conditions, and does the resulting geometry predict binding and generalization errors in choice?

## Scientific consequence

Evidence for largely parallel representations would favor abstraction but leave open how offer identity is preserved; evidence for fully orthogonal representations would support binding but predict poor transfer of value codes across positions. Evidence for semi-orthogonal geometry would support an intermediate mechanism in which nonlinear or interaction-related structure reduces misbinding while retained shared structure permits generalization. Neural geometry that predicts the pattern of spatial, temporal, binding, and generalization errors would further connect representational organization to decision behavior; failure of those predictions would weaken that mechanistic account.

The question is scientifically valuable because it links a general computational problem—maintaining feature identity while reusing abstract representations—to measurable population geometry and concrete behavioral consequences. It offers a pattern for turning a representational trade-off into a discriminating question by testing competing geometries and asking whether they predict behavior, rather than treating neural decoding as sufficient evidence of mechanism.
