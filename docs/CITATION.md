# Citing Maieusis

[Documentation home](INDEX.md)

For reproducibility, cite the exact software version used. The recommended
citation for Maieusis v0.1.0 is:

> Xu, Y., & Doiron, B. (2026). *Maieusis* (Version v0.1.0) [Computer
> software]. Zenodo. https://doi.org/10.5281/zenodo.21388806

## Which DOI should I use?

- **Version DOI — [`10.5281/zenodo.21388806`](https://doi.org/10.5281/zenodo.21388806):**
  use this when reporting work performed with Maieusis v0.1.0. It resolves to
  the Zenodo record containing the archived source snapshot for this exact
  release.
- **Concept DOI — [`10.5281/zenodo.21388805`](https://doi.org/10.5281/zenodo.21388805):**
  use this only when referring to Maieusis as an evolving software project
  without identifying a particular version. It represents all versions and
  resolves to the latest Zenodo record.

GitHub's **Cite this repository** panel reads the root
[`CITATION.cff`](https://github.com/BeibaiDraco/maieusis/blob/main/CITATION.cff)
and offers APA and BibTeX. Zenodo's
[v0.1.0 record](https://zenodo.org/records/21388806) provides additional
citation styles and export formats.

## Technical report

A separate technical report is planned but is not yet the preferred citation.
Until it is published, cite the version-specific software DOI above. Once the
report has its own DOI, this guide and `CITATION.cff` will distinguish citation
of the method from citation of the exact software release; the immutable
v0.1.0 tag and release assets will not be rewritten.
