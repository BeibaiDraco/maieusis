# Limitations

Maieusis v0.1.0 is a Research Preview.

## Scientific limitations

- A source-backed question-formation pattern can still be unimportant or fail
  to transfer to a new field.
- Dataset planning can miss undocumented structure, data-quality problems, or
  domain-specific constraints.
- Independent AI review reduces self-approval but does not establish truth.
- No product novelty search runs in v0.1.0; novelty is `not_assessed`.
- A plan is not a result. No dossier demonstrates an effect or supports a
  confirmatory claim.
- Authority labels describe evidence/review state, not scientific correctness.
- Human domain expertise remains valuable, especially for construct validity,
  scientific importance, ethics, and post-hoc interpretation.

## Scope limitations

- The demos are neuroscience demonstrations, not proof of broad disciplinary
  validation.
- Work with collaborators in climate science, physics, astronomy, finance,
  social science, and psychology is ongoing.
- Dataset adapters, local dependencies, and lawful data access remain the
  user's responsibility.
- Paywalls and incomplete scholarly metadata can lower PaperBank or literature
  authority.

## Operational limitations

- Serious runs require a coding-agent host, local tools, real dataset access,
  and model APIs; they can incur subscription and API usage.
- Provider availability, rate limits, model entitlements, and coding-agent
  concurrency can vary by account and time.
- A clean run can still end with rejected, deferred, or incomplete families.
  Those are honest outcomes, not automatically bugs.
- `resume` prevents repayment only when receipt-bound identity remains valid.
- Source-paper PDFs and most datasets cannot be redistributed in this repo.

## Closed capabilities

The downstream analysis-execution bridge and confirmatory analysis remain
closed. No model output, config change, accepted dossier, or
release demo authorizes them.

Report software failures through GitHub. For scientific limitations or
collaboration help, contact `dracoxu@uchicago`.
