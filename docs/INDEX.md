Each demo exposes a curated set of readable PaperBank, literature, dataset,
Question Scientist, and family-dossier artifacts. The public repository never
includes source-paper PDFs, raw model captures, or hidden audit sidecars. Each
demo provides a paper manifest with bibliographic identities, hashes, and
lawful acquisition instructions.
